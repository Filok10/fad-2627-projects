# Online Shoppers Purchasing Intention Dataset

* **Da dove viene e licenza:** Il dataset proviene dall'UCI Machine Learning Repository. È rilasciato sotto licenza Creative Commons Attribution 4.0 International (CC BY 4.0).
* **Quale file scaricare e come salvarlo:** Il file da scaricare si chiama `online_shoppers_intention.csv` e deve essere salvato all'interno di questa stessa cartella (`data/`) mantenendo il nome inalterato.
* **Che cosa è una riga:** Ogni singola riga rappresenta una specifica sessione di navigazione di un utente all'interno del sito web di e-commerce (rilevata nell'arco di un anno).
* **Come sono stati raccolti:** Si tratta di dati puramente osservazionali. I dati sono stati raccolti automaticamente in background (presumibilmente tramite strumenti di tracciamento come Google Analytics) monitorando il traffico reale e il comportamento degli utenti sul sito, senza alcun esperimento controllato o questionario sottoposto agli utenti.

Per scaricare automaticamente il file, esegui lo script `download.py` contenuto in questa cartella.
